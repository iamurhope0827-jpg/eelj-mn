# Hosting

- Provider: GitHub Pages.
- Live URL: https://iamurhope0827-jpg.github.io/eelj-mn/
- Source repository: https://github.com/iamurhope0827-jpg/eelj-mn
- Publishing branch: `main`, repository root (`/`).
- Static files: `index.html`, `styles.css`, `app.js`, and `assets/`.
- `.nojekyll` disables Jekyll processing.

Push the updated source to `main` to publish changes. No server build, credentials in source, or third-party runtime is required. The prototype uses browser-local demo data, as documented in README.md.

Historical Sites configuration remains only in the ignored local `.openai/` directory and local archive branch. It is not the publishing target.
